# ModeliPlanet

Projet C++ pour la modélisation 3D d'une planète.

## Architecture du projet

- `src/` : Code source principal
- `include/` : Fichiers d'en-tête (headers)
- `CMakeLists.txt` : Configuration du projet et dépendances (OpenGL, GLFW, GLM)
- `main.cpp` : Point d'entrée

## Dépendances
- OpenGL
- GLFW
- GLM

## Compilation

```sh
mkdir build
cd build
cmake ..
make
./ModeliPlanet
```
